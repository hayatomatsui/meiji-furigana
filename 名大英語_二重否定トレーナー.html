二重否定トレーナー
「消して肯定」＋ 3つの補正

否定を数える → 偶数なら肯定 → 強さと働きを確認する。隠れ否定と部分否定のワナも練習します。

基本：両方消して肯定で考える

None of this is to say that happy or meaningful lives cannot be good ones.

None of this is to say that happy or meaningful lives cannot be good ones.

→ 「幸福で意味のある人生も良い人生でありうる」

意味はこれで取れる。ただし筆者は「〜だ」と主張しているわけではない。「〜でありえない、と言うつもりはない」＝誤解の予防（譲歩）。このあとに「しかし〜」で本当の主張が来る。

手順（4ステップ）

  1. 否定を数える：not / no / never だけでなく、隠れ否定（few, hardly, fail, lack, deny, without, prevent, free from, far from, unless, im-/un-）も数える。
  2. 偶数なら肯定、奇数なら否定：同じ節の中で数える。別の節にある否定や、名詞・形容詞の中にある否定（unexamined など）は数えない。
  3. 強さを補正：二重否定は控えめな肯定になりやすい。not uncommon ＝「かなりよくある」。「いつも」「全員」まで強めない。
  4. 働きを確認：It is not that … not / None of this is to say … not / does not deny ＝ 譲歩。次の but / rather / however を探す。

「消す」が通用する度合い

消すだけでOKFew would deny … → 多くが認める。
cannot … without → 必ず〜する。
消してから補正not uncommon → 「よくある」より少し控えめ。
It is not that … not → 譲歩として読む。
消すと誤訳部分否定：Not all X are without cost
✗ すべてのXはコストを伴う
○ コストを伴うXもある
