how の読み分け

疑問副詞 / 間接疑問
0 / 14

how が主語に見えてしまうのはなぜか。まず語順スイッチで何が動いて何が動かないかを目で確かめ、そのあと三種類のドリルで判定手順を身体に入れます。

Ⅰ語順スイッチ

同じ内容を三つの形に切り替えます。動くのは主語 hunger と助動詞 can の前後関係だけ。それ以外は一語も動きません。

hunger主語 can助動詞 how疑問副詞

Ⅱ主語の核はどれか

朱の下線を引いた動詞について、その主語となる名詞の核を一語クリック。how が主語になれるかどうかが、ここで決着します。

動詞 affects の主語の核は？

核は hunger。how を外した Hunger affects learning が完全な文として成立します。how は「どのようにして」という副詞情報を外から被せているだけで、名詞の席には座っていません。

ちなみに is unclear の主語は How hunger affects learning という節まるごと。節が名詞のかたまりとして主語になっているのであって、how 単独が主語なのではありません。

動詞 experienced の主語の核は？

核は children。主語は how ではなく how many children という名詞句全体で、how は many を修飾しているだけです。

この型が誤読の温床。how + 名詞 という並びを見ると「how が主語だ」と処理してしまいがちですが、実際に主語なのは後ろの名詞。how hunger ... と how many children ... は表層が似ていて中身が違います。

動詞 was の主語の核は？

核は effect。元の形は the effect was strong で、補語の strong が how ごと文頭に引き抜かれています。

how の直後が形容詞なら、その塊で一単位。how strong をひとまとまりとして扱えば、主語が後ろに残っていることが見えます。

動詞 works の主語の核は？

核は program。how 節は shows の目的語で、文中では名詞のかたまりとして働いています。

how の後ろは the program works とSVが揃った完全文。副詞は名詞の席を取らないので、穴が空きません。

動詞 collect の主語の核は？

核は researchers。疑問文で倒置が起きても、主語が how になることはありません。

倒置しているのは did と the researchers の前後関係だけ。five 語の中で how だけが最初から動かない位置にいる——それが副詞である証拠です。

Ⅲ疑問文か、名詞節か

how が導くまとまりがどちらかを判定します。決め手は助動詞（または do/be）が主語の前にあるか後ろにあるか、それだけ。

How can hunger affect learning?

疑問文。can が主語 hunger の前にある＝倒置。それ自体が独立した文です。

I don't know how hunger affects learning.

名詞節。主語 hunger が動詞 affects の前に戻っており、倒置していません。know の目的語として働く文の部品なので、文の形を崩さず SV 順を保ちます。

The strength of the study is in showing how it works.

名詞節。前置詞 in ＋動名詞 showing の目的語が必要な位置なので、そこに入れるのは名詞のかたまりだけ。意味を読む前に、位置だけで名詞節だと確定します。

Lesson 11 の問2(c) がまさにこの形でした。

Do you know how he solved it?

名詞節。ここが引っかかりどころです。文全体は疑問文（Do you と倒置している）ですが、how が導く how he solved it の部分は倒置しておらず、know の目的語＝名詞節。

外側の文の種類と、how 節の種類は別勘定。これを混同すると Do you know how did he solve it? という誤文を作ってしまいます。

Ⅳthe way と how は同居できるか

how が関係副詞かどうかを分ける実地テスト。英語として成立するものに ○、しないものに ×。

This is the way he solved it.

成立。先行詞 the way を関係副詞（省略）が受ける形です。

This is how he solved it.

成立。先行詞を置かず how だけで受ける形。上と下、どちらか一方を選ぶのが原則です。

This is the way how he solved it.

不成立。先行詞 the way と how は共存できません。ここが how の特殊なところで、when / where / why には the time when, the place where という共存形があるのに、how だけ許されない。

この This is how... を「先行詞 the way が省略された関係副詞」と説明する参考書もあれば、「先行詞を含んだ形（関係代名詞 what に相当）」とする説明もあり、学校文法の中でも扱いが割れています。いずれにせよ「先行詞＋how」が作れない以上、how を関係副詞として扱う場面はほぼありません。

This is the way in which he solved it.

成立。硬い書き言葉で使われる形です。how が使えない場面（先行詞を明示したいとき）はこちらに逃がします。共存できないのは the way + how の組み合わせに限った話だと分かります。

Ⅴまとめ

ドリルで確かめたことを、判定に使える形に畳んでおきます。

なぜ how の後ろは完全文なのか

種類語後ろに続くもの
疑問代名詞what / who / which不完全文（S か O が欠ける）
疑問副詞how / when / where / why完全文（S も O も揃う）

代名詞は文中の名詞の位置を自分で占めるので穴が空く。副詞は名詞の位置を取らないので穴が空かない。how が主語になれないのは、この一点から出てくる帰結です。

判定手順

  1. how の直後は名詞・形容詞・副詞か。Yes ならその塊で一単位（how many children / how strong）で、主語になりうる
  2. No なら how は単独の副詞。後ろは完全文で、主語は別にある
  3. 助動詞（do / be / can など）が主語の前か後ろか。前なら疑問文、後ろなら名詞節

呼び名

間接疑問（間接疑問文）——学校文法で最も一般的。疑問詞節 / 名詞節——品詞・働きに着目した言い方。生徒には「間接疑問」で通じます。関係副詞ではありません。
