「式」と「方程式」を見分けよう

混同しやすい数学用語を、ペアで比べてスッキリ整理!

1文字式と方程式

問以下の式を見て、どちらが文字式でどちらが方程式なのか説明して下さい。
a + 2a + 3 =
2x + 3 = 0
答えを見る
文字式(の計算)
a + 2a + 3 =
  • 「=」の後ろが空いている → 「計算して簡単にしなさい」という意味
  • することは「整理する」
  • 答え: 3a + 3 (答えも式)
方程式(一次方程式)
2x + 3 = 0
  • 「左辺 = 右辺」が成り立つ x を探す
  • することは「解く」
  • 解: x = −3/2 (答えは数)
💡 ポイント: 文字式の「=」は「計算するとこうなる」という記号。方程式の「=」は「両辺が等しい」という条件。文字式は整理する、方程式は解く。

2展開と二次方程式

問展開と二次方程式も同じです。以下の式を見て、どちらが展開でどちらが方程式か説明して下さい。
( x + 3 ) ( x + 4 ) =
x² + 4x + 3 = 0
答えを見る
展開(文字式の計算)
( x + 3 ) ( x + 4 ) =
  • かっこを外して「整理する」だけ
  • = x² + 7x + 12
  • x の値を求めるわけではない
二次方程式
x² + 4x + 3 = 0
  • 成り立つ x の値を「解く」
  • 因数分解して (x + 1)(x + 3) = 0
  • 解: x = −1, −3
💡 ポイント: 展開・因数分解は式の変形(道具)。二次方程式は解くもの(問題)。道具と問題を区別しよう。

3二次方程式と連立方程式

問二次方程式と連立方程式は混同しがちです。どう違うでしょうか。
{x + y = 5
2x − y = 1 連立方程式
x² + 4x + 3 = 0 二次方程式
⭐ 文字が二つあっても二次方程式ではありません。（連立方程式は、連立二元一次方程式と言います）

二次方程式は二乗を含む方程式のことです。

x² + 4x + 3 = 0 二次方程式
x² = 16 二次方程式
💡 展開して二乗を含む方程式も二次方程式です。
( x + 3 ) ( x + 4 ) = 0 は、展開すると x² + 7x + 12 = 0 となるので二次方程式です。

同様に高校で習いますが、三次方程式は三乗を、４次方程式は四乗を含む方程式です。

x³ − 8 = 0 三次方程式
x⁴ − 16 = 0 四次方程式
