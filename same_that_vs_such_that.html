そっくりだけど別物 ── the same … that と such … that

どちらも「形容詞っぽい語 + that」で見た目が似ていますが、that の正体がまったく違います。

結論を先に言うと、the same … that の that は関係代名詞（名詞を修飾）、such … that の that は結果を表す接続詞（節をつなぐ）。
「同一だと言う」のか「程度・結果を言う」のかで、意味の方向が違います。
同一を表す
the same A that B
「B するのと同じ A」
that の正体
関係代名詞（A を後ろから修飾）
that の働き
直前の名詞 A を説明する形容詞節をつくる
意味の核
A と B が「同じものだ」と述べる
仲間
the same A as B も同じ用法
This is the same bag that I lost yesterday.
これは昨日なくしたのと同じカバンだ。
She goes to the same school that I go to.
彼女は私が通っているのと同じ学校に通っている。
One source is the same fertilizers that pollute the ground.
源の一つは、地面を汚染するのと同じ肥料だ。
程度・結果を表す
such (a) A that B
「とても A なので B」
that の正体
接続詞（結果の副詞節を導く）
that の働き
「その結果〜」という別の節をつなぐ
意味の核
程度が高く、その結果どうなったかを述べる
仲間
so + 形容詞 + that B も同じ意味
It was such a heavy bag that I couldn't carry it.
とても重いカバンだったので、運べなかった。
He spoke so fast that no one understood him.
彼はとても速く話したので、誰も理解できなかった。

見分け方のコツ

  • the same … that → that を消して「同じA」と訳せる。that 節は A の中身説明。
  • such … that → 「とても…なので」と結果でつながる。that の後ろは独立した文になっている。
  • 迷ったらthat 節を取り除いてみる。名詞が説明不足になる→ same（関係代名詞）／文として成立する→ such（結果）。
the same … that／as ＝ 同一　｜　such … that ＝ 程度・結果
