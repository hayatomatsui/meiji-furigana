01 拾った概念

テキストから直接取り出したもの

Composition

定義可能性は同一性ではない

点は「体積の入れ子」「線の対」「平面の三つ組」のいずれとしても等しくうまく定義できる。だがそれは、一つの世界の内部でそれらが同一物だという意味ではない。for all these are different from each other.

複数の構成経路がありうることと、それらが一つの自己に重ね合わせ可能であることは、別のことである。

Weighting

在庫の差ではなく、振り分けの差

Goodmanは自分の言い方をその場で訂正する。「一方に種が欠けている」ではなく、「両方とも同じクラスを持ち、関連する種／しない種への振り分けが違う」。世界間の差異が、在庫の差から強調の差へ移される。

Weighting

ピエロのキリストとレンブラントのキリスト

指しているもの（denotation）は同じでも、何を際立たせたかが違えば別の世界に属する。grue が時間的境界で種を裂いたのと同じ操作を、絵画が行っている。

Weighting

exemplification は逆方向に走る

指示は記号から外の対象へ向かう。例示は逆で、記号が自身の持つ特徴を掲げる。悲しみという語を一つも含まない詩が、その言語の質において悲しみを表現する。

これも劣らず記号的な指示機能であり、世界制作の道具である。

Weighting → Ordering

重みづけは二値ではなく階層をなす

relevant／irrelevant の二分だけではない。有用性や価値の格づけは、しばしば二分法ではなく階層を生む。そしてその階層は順序づけの一種である——ここで (c) へ橋が架かる。

02 対話で立ち上がった糸

読みから派生したもの

社会 · ANT

アクターはその都度立ち上がる

中根とダンボールで遊んだアクターと、タモちゃんと糸電話で遊んだアクターは別バージョン。ラトゥールのアクターも本質を持たず、関係のネットワークのなかで立ち上がる。

ただし切り口が一段ずれる。ANTは「誰が参加しているか」を問い、Goodmanは「同じ参加者でもどの側面が relevant kind か」を問う。Goodmanの weighting は、在庫が同じでも成立する。

個人

誰かを語るとき、例示できるかが問題になる

ダンボールと遊ぶ人は「私は遊ぶ人間だ」と denote していない。ただその質を掲げていた。人物評は denotation の在庫合戦になりがちだが、実際に相手を知っている人だけが持っているのは例示の記憶の方である。

個人 · versioning

四象限：語ったものと、掲げていたもの

versioning の記述は、二つの軸の交差で読める。

社会 · 制度

結婚は差異を社会的に登録する装置

二人のあいだでだけ relevant だった種を、公的な世界のなかで relevant kind として承認させる手続き。個人の worldmaking が制度と接続する結節点。

留保：「新しい世界を産むことが正しいバージョンの証明になる」は、Goodmanからは支持されない。彼の rightness は fit・coherence・受容の履歴で測られ、産出の事実が正しさを証明するという論理はない。それを認めると「より多く作った版が正しい」となり、彼が拒否した単一の特権的基準の裏返しになる。二つの主張は分けた方が強い。
個人

関係が変わることを、誰のバージョン変化として書くか

「相手を変えることもバージョンの違い」は形式的には成立する。だが二つの負荷がかかる。

一つは記述と正当化の混同。「別バージョンである」は記述だが、「だからどちらも等しく正しい」へ滑りやすい。Goodmanは版が複数あることがどの版でもよいことを意味しないと繰り返す。right versions と mere versions の区別が議論の生命線。

もう一つは相手が背景に退くこと。同一性の条件は自他が共同で構築する——その原則を適用すれば、変わったのは一人のバージョンではなく、二人で作っていた世界が終わった、という記述になる。

哲学 · 物語

河合隼雄と Goodman のズレ

物語は ordering そのものである。同じ出来事の集合でも、どれを発端とし、どれを転回点とするかで別の人生になる。Goodmanが「地図の空間的順序は旅の時間的順序へ翻訳される」と書いたその操作が、物語の作られ方である。

ただし役割が違う。河合の物語論は臨床から出ている——そうしないと人が生きられないから必要とされ、その人を救うかどうかで測られる。Goodmanの version にその基準はなく、慰めになるかどうかは正しさに入らない。

注意：「生きるとは自分のバージョンを作り出すこと」は、河合から作ってよいという許可を、Goodmanから複数ありうるという多元性を取る。だが河合の臨床的な歯止め（その物語で本当に生きられるか）も、Goodmanの認識論的な歯止め（fit しているか）も、両方こぼれ落ちる危険がある。

河合の方が先に行っている点：自分で自分の物語を作れないときがあると知っている。だから他者が要る。物語は単独制作ではなく、聴かれることで成立する。

03 時間と空間の往復

本セッションで最も遠くまで届いた線

時間を空間化するものが近代的なもの、合理主義で、空間を時間化するのがロックである。

橘川幸夫
社会 · 企業

「時間を支配している」という記述は非対称である

覇権を志向する企業は、空間を能動的に組織している。市場を分割し、領域を獲得し、拠点を配置する——ここには支配と呼べる作用がある。

しかし長寿企業の側に、同じ強さの能動性があるとは限らない。あるのは「生き延びた」という結果だけで、そこに時間を支配する意志や技術があったかは結果からは読み取れない。空間の支配は行為だが、時間の存続は多くの場合、結果である。

この非対称を見落とすと生存者バイアスに落ちる。消えた日本企業は膨大にある。残った側だけを見て「時間を支配した」と記述することは、結果を原因に読み替える操作にほかならない。

立て直し

支配の対象ではなく、relevant kind の差

両者の違いは「空間か時間か」ではなく、何を relevant kind として数えているかの違いである。覇権型は市場シェア・領域・拡大速度を、長寿型は継承・取引先との関係・次代へ渡せるかを関連する種として組織する。在庫は同じ「会社」でも、前景に置くものが違えば別の世界が立ち上がる。

この立て方の利点は優劣の判定を留保できること。「すぐ消える／長く続く」を軸にすると長寿が自動的に勝ちになるが、存続の長さ自体が rightness の基準かは問い直される。存続の事実は、正しさを証明しない——「産むことが正しさの証明になる」への留保と同じ構造。

実践

この読書そのものが往復である

橘川の定式は対立として立てられている。だが実践のレベルでは、二つは往復として現れる。

Goodmanの本は空間的対象であり、目次も章立ても一望できる。それを数ヶ月かけて順に通過する時間へ翻訳している。ダッシュボードは、その通過の軌跡をもう一度空間化したもの。そして再び時間化して、次の節を読む。

翻訳は一方向ではない。時間化して読み、空間化して記録し、また時間化して進む——この循環自体が worldmaking の運動である。対立として立てられたものを、実践としては両方使っている。

企業論にも戻せる。覇権型と長寿型を「空間か時間か」で二分するのではなく、両者がその往復をどう回しているかで見る方が、記述として強い。

既存の一行に、本節が加えたもの

完全合理性は武器を作り、限定合理性は歌を作る。

既存 anchor
更新

限定合理性は二値ではなく、濃淡を持つ

前節までの限定合理性は「捨てる／残す」の二値で語られていた。ここでGoodmanは、格づけが階層を生むことを認める。全捨象でも全保持でもなく、どれをより前に、どれをより後ろにという配分。

歌は、音を鳴らす／鳴らさないの二進法ではなく、強弱の階層で旋律になる。weighting が ordering へ滑り込むこの一歩は、比喩を字義通り裏書きする。

候補

捨てることが、作ること

全クラスを relevant kind として扱う世界は、アクセントを一つも持たない世界であり、世界として組織されていない。歌にならない。三本柱の同型性（Goodman／Nietzsche／Simon-Sarasvathy）に渡す四本目の梁としての候補。
