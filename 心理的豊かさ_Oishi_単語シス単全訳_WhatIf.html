      1What if ...? は「主節の省略」

      英語表現・文法上の基本

      What if ...? は、疑問詞 what のうしろにあるはずの主節がまるごと省かれ、if 節だけが残った形です。省略される部分は文脈で決まります。

      What would happen if ... ?もし～なら、何が起こるだろう？（どうなるだろう）
      What should we do if ... ?もし～なら、どうすればいいだろう？
      What would you think / say if I told you ... ?もし私が～と言ったら、あなたはどう思う（言う）だろう？ ← 本文はこれ

      主節が消えているぶん、「もし～だったら……？」と答えを相手に委ねる、余韻のある問いになります。和訳するときは、省略された「どうなるだろう／どうしよう／どう思うだろう」を文脈に合わせて補うのがコツです。

      2if のあとの時制で、意味が3つに分かれる

      いちばん大事な読み分け。英作文でもここを間違えやすい

      現在形（直説法）

      What if ＋ 現在形

      • What if it rains tomorrow?明日雨が降ったらどうしよう。
      • What if we miss the last train?終電を逃したらどうなる？
      十分ありうる未来への心配・確認。
      過去形（仮定法過去）

      What if ＋ 過去形

      • What if I told you that we could all be rich?そう言ったらどう思う？（本文）
      • What if we tried a different approach?別のやり方を試してみたらどうだろう。
      • What if you won the lottery?宝くじが当たったらどうする？
      現実から一歩引いた「仮に」の話。提案に使うと控えめで丁寧になる。
      過去完了（仮定法過去完了）

      What if ＋ had 過去分詞

      • What if I had taken that offer?あのオファーを受けていたら、どうなっていただろう。
      • What if she hadn’t missed the train?彼女があの電車に乗り遅れていなかったら？
      過去の事実に反する想像。後悔・「たられば」。
      現在形と過去形の差：What if it rains? は「降りそうだけど、降ったら？」、What if it rained? は「（たぶん降らないけど）仮に降ったとしたら？」。どちらも文法的に正しく、違うのは話し手が見込んでいる可能性の高さです。

      3会話での4つの働き

      同じ What if でも、場面によって「心配」にも「提案」にも「後悔」にもなる

      ① 仮定・懸念

      もし～だったらどうしよう／どうなるだろう

      • What if it rains tomorrow?明日雨が降ったらどうしよう。
      • What if we miss the last train?終電を逃したらどうなる？
      未来の不確定な事態に対する心配や、リスクの想起。
      ② 提案・促し

      ～してみたらどうだろう？

      • What if we start from scratch?いっそ最初からやり直してみるのはどう？
      Why don’t we ...? や How about ...ing? とほぼ同じ。相手に柔らかく新しいアイデアを投げかける。
      ③ 反実仮想・後悔

      あのとき～していたらどうなっていただろう

      • What if I had taken that offer?あのオファーを受けていたらどうなっていただろう。
      過去完了形を伴う。選ばなかった選択肢への想像。
      ④ 修辞的な導入

      もし～と言ったら、どう思う？

      • What if I told you (that) ...?（本文の第1文）
      答えを求めず、聞き手の常識をひっくり返す「前振り」。スピーチ・プレゼン・エッセイの書き出しの定番。
      豆知識：映画『マトリックス』のモーフィアスの画像に What if I told you ... と添えるネットミームが有名です。「あなたが当たり前だと思っていることは、実は違うとしたら？」という④の働きを、そのままネタにしたものです。

      4本文の What if を精読する

      What if I told you that we could all be rich?

      What would you think if I told you [ that we could all be rich ] ? told＝仮定法過去（まだ言っていない。「仮に言ったら」）／could＝仮定法の could＋時制の一致（「なれるかもしれない」）

      働きは「④ 修辞的な導入」です。rich と聞けば、読者はまずお金持ちを思い浮かべます。筆者はその思い込みを、直後の文で鮮やかに裏切ります。

      伏線の回収（第6段落）
      ... a third route to fulfilment: psychological richness.
      充実した人生への第三の道＝心理的豊かさ

      つまり冒頭の rich は、文章全体のキーワード psychological richness（心理的豊かさ）への伏線です。What if の一文が、テーマへの入口になっています。

      訳し方の3段階

      直訳もし私が、私たちはみな豊かになれると言ったら、どうだろうか。
      自然な訳私たちはみな豊かになれる——そう言ったら、あなたはどう思うだろうか。
      意訳誰もが「豊か」になれる、と聞いたら驚くだろうか。
      和訳答案のコツ：「もし～と言ったら」で止めず、省略された主節（どう思うだろうか／どうだろうか）を補うと減点されにくくなります。could を「できた」と過去の意味で訳すのは誤りです。

      5what を使う仲間の表現

      本文第6段落の What of ...? も同じ仲間

      表現意味・働き例
      What if ...?もし～ならどう？（懸念・提案・後悔・導入）What if it rains?
      What about ...?～はどう？（提案・話題の追加）What about Sunday?
      What of ...?～はどうなのか（What about のやや文語的な形）← 本文第6段落What of curiosity, ambition and exploration?
      So what if ...?～だからどうだっていうの（開き直り）So what if I’m late?
      If only ...!～でさえあればなあ（願望・後悔）If only I had studied harder!
      Suppose / Imagine (that) ...仮に～だとしよう（仮定を先に置く）Suppose you won the lottery. What would you do?
      what-if（名詞）「たられば」の仮定Life is full of what-ifs.（人生はたらればだらけだ）
      what-if（形容詞的）仮定のa what-if scenario（仮定のシナリオ）

      6What if と「後悔」——本文のテーマにつなげる

      第6段落 embracing the pursuit of psychological richness can make us less prone to regret

      後悔は、What if I had ...?（あのとき～していたら）という頭の中のシミュレーションから生まれます。心理学ではこれを反実仮想（counterfactual thinking）と呼びます。

      「やったこと」と「やらなかったこと」の後悔を比べると、長い目で見れば人はやらなかったことのほうを強く後悔しやすい、という研究があります（Gilovich & Medvec, 1995）。

      一方、本文の筆者は、心理的豊かさを追い求めると後悔しにくくなると述べます。it matters less if the thing you did went wrong（やったことがうまくいかなくても、それほど問題ではなくなる）。結果が失敗でも、「やってみた経験」そのものが人生の豊かさに加わるからです。

      読み方の一つ：「やらなかった what if」を減らして、回り道（detours）や転機（turning points）を自分から経験しにいくこと。それが筆者の言う心理的に豊かな人生だ、と読むこともできます。

      7ビジネス・意思決定での What-if 分析

      不確実性に対処するためのシナリオ分析（感応度分析）

      What-if シナリオの例①主要原材料の価格が20%高騰したら、利益率はどうなるか？
      What-if シナリオの例②計画が3か月遅延した場合、どの工程でボトルネックが発生するか？

      目的は二つです。前提条件を変数として動かし、結果への影響度を測ること。そして最悪のケース（ワーストシナリオ）をあらかじめ織り込み、許容できる損失や代替策（Plan B）を事前に設計しておくことです。

      身近な例では、Excel の［データ］タブに「What-If 分析」があり、「シナリオの登録と管理」「ゴール シーク」「データ テーブル」で前提を動かした結果を比べられます。

      英語で使う表現：run a what-if analysis（What-if 分析を行う）／a what-if scenario（仮定のシナリオ）／the worst-case scenario（最悪のシナリオ）／a Plan B（代替策）

      8思考実験・発想法としての What if

      現状の常識や制約条件をあえて外し、新しい可能性を拓くための問いのきっかけ

      前提破壊の問い①もし予算がゼロだったら、どうやってこの問題を解決するか？
      前提破壊の問い②もし競合がこの事業を買収したら、どんな手を打ってくるか？

      効果：既存の枠組み（認知バイアス）を強制的に外し、創造的な跳躍を生み出します。

      科学の世界でも What if は強力です。アインシュタインは少年時代に「光と同じ速さで光を追いかけたら、光はどう見えるか」と考え、それがのちの特殊相対性理論の出発点になったと回想しています。ランドール・マンローの『ホワット・イフ？』（原題 What If?, 2014）は、「野球のボールを光速で投げたらどうなるか」といった突拍子もない仮定に、科学で大真面目に答える本です。

      9創作・カルチャーにおける What if（代替現実）

      「選ばれなかった道」を描くことで、選択の重みが浮かび上がる

      歴史改変・パラレルワールド「もし第二次世界大戦で枢軸国が勝っていたら？」——フィリップ・K・ディック『高い城の男』（1962年）
      マーベル『What If...?』正史と異なる分岐点を描いたアンソロジー。コミックは1977年から、アニメシリーズはディズニープラスで2021年から。
      人生のオルタナティブ映画『スライディング・ドア』（1998年）は、地下鉄に乗れたかどうかで分かれた二つの人生を並行して描く。
      「選ばれなかった道」ロバート・フロストの詩 The Road Not Taken。森の分かれ道でどちらを選ぶかという、人生の分岐の象徴としてよく引用される。

      本文の筆者が理想とする「立ち止まり、回り道をし、転機を迎える人生（a life with stops, detours and turning points）」は、こうした分岐の連続そのものです。選ばなかった道を想像する力が、選んだ道を味わう力にもなります。

      英作文：What if を使って英語に

      英作文のコツ：if のあとの時制で意味が決まります。未来の心配なら現在形、仮定や控えめな提案なら過去形、過去の後悔なら過去完了。仮定法では be 動詞を主語に関係なく were にするのが正式です。

      読解の地図（論の流れ）

      1. 第1段落 導入：「豊かさ」をお金ではなく経験という通貨で考えよう。良い人生への道は従来幸福と意味の二つ。だがどちらにも限界がある。
      2. 第2段落 幸福の限界①：幸福は「運」から「努力と成功の結果」へ。その結果、悲しみや怒りが個人の失敗に見えてしまう。
      3. 第3段落 幸福の限界②：期待を下げれば幸福になれる（デンマーク・フィンランド）。大きな出来事にはすぐ慣れる（快楽のトレッドミル）。でも、楽な授業だけ取る学生のようで物足りない。
      4. 第4段落 意味の限界①：世界を変えるような壮大な理想は重荷で手が届かない。小さな日々の営みに意味を見出すほうが現実的。
      5. 第5段落 意味の限界②：意味の追求は「仲間とそれ以外」の間に線を引き、異なる人への思いやりを損なうことがある。
      6. 第6段落 第三の道：心理的豊かさ＝多様で波乱に富んだ経験に満ちた人生。心の回復力が高まり、後悔しにくくなる。
      7. 第7段落 逆境でも：病気・死別・経済的破綻のときでも、豊かさの視点なら災難を人生の織物に組み込める。
      8. 第8段落 具体例：タクシー運転手リンダの人生。豊かさの副産物として幸福と意味もついてくる。

      ※ 問題提起（1）→ 幸福の限界（2・3）→ 意味の限界（4・5）→ 第三の道の提示（6）→ 補強（7）→ 具体例（8）という構成。空所①〜④の文は、この「限界の指摘→譲歩→転換」の節目に入る。

      2研究テーマ

      幸福と人生の意味人はどんなときに幸せや生きがいを感じるのか。その感じ方は、文化によってどう違うのか。
      幸せを左右する「社会の条件」所得格差、引っ越しの多さ（居住流動性）、街の歩きやすさなど、暮らしている環境が心に与える影響。
      心理的豊かさ幸福・意味に並ぶ「第三の良い人生」。共同研究者のエリン・ウェストゲートとともに、2022年に学術誌 Psychological Review で提唱した。

      30か国の辞書にある「幸福」の定義を調べたところ、多くの文化で「幸運・恵まれた状況」と定義されていた。アメリカ英語の辞書では、1920年代以降、「内面のよい気分」という定義に変わっていった。Oishi, Graham, Kesebir & Galinha, “Concepts of Happiness Across Time and Cultures” (2013)
      第6段落
      ... led me and my research lab to sketch out a third route to fulfilment: psychological richness.
      私と私の研究室は、充実した人生への第三の道を描き出すに至った。それが「心理的豊かさ」である。
